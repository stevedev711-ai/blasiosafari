# Asset list

Every image is referenced by key from `content/images.ts`. To replace one, drop the new file into `public/images/` and update that entry (src, alt, width, height, credit, status). The image credits page (/image-credits) updates automatically.

**Rights status.** The preview images are openly licensed photographs from Wikimedia Commons, downloaded at 1920px. CC BY and CC BY-SA licences allow commercial use **with attribution**, which the site provides in captions and on /image-credits. CC BY-SA also requires that adapted versions (crops, edits) are shared under the same licence. They are suitable for a preview. For launch, replace them with owner-supplied or properly licensed photography, at least for the hero and destination heroes. None of these images depict a property Blasio represents, and no named property appears on the site.

**Hero video.** None supplied. When you have approved footage, set `heroVideo.src` in `site.config.ts` (H.264 MP4, muted, 10–20 s, ideally under 6 MB). It plays only on screens 900px and wider for visitors without reduced motion. Everyone else sees the still image, which is also the poster.
